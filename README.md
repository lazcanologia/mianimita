# Mi DigiAnimita

## Experiencia interactiva de investigación artística

**Mi DigiAnimita** es una experiencia digital interactiva desarrollada en HTML, CSS y JavaScript que invita a construir una animita mediante la selección y disposición de objetos significativos.

El proyecto surge desde el prcoeso de exploración artística de la investigación doctoral: Animitas / Disensos y objetos sensibles. Esta investigación aborda las animitas chilenas como espacios de construcción de memoria, identidad, así como extensión afectiva de un rito mortuorio. Esta obra se concentra en la relación afectiva de los objetos sacralizados, que actúan como portador de historia y mediador sensible entre la autobiografía del usuario y el valor de uso de los objetos exvotos. Los objetos son considerados como extensiones sensibles de las potencias sensoriales que el cuerpo humano posee por default, por ello, los objetos sacralizados son entendidos como una extensión de la memoria vital de alguien que ha muerto y cuya memoria es re construida a partir de ellos.

En esta experiencia, cada visitante crea una composición única a partir de objetos que funcionan como fragmentos de una biografía imaginada o recordada, una animita digital que se construye mediante objetos de la cultura popular, cuya relación es transversal y transetaria. Los objetos no operan solamente como un ladrillo visual, también activan la interpelación del objeto entendido como un archivo que también pregunta /mal de archivo/ La animita se transforma así en un **autorretrato biográfico objetual**. Posterior a la construcción surge una Epicrisis de Animita, archivo digital descargable que describe las operaciones sensibles que el usuario puede desarrollar dentro del espacio virtual.

---

## Concepto

Las animitas constituyen formas populares de memoria donde conviven elementos religiosos, afectivos y cotidianos. Sus objetos no funcionan solamente como adornos, sino como huellas materiales de una vida.

**Mi Animita** traslada esta práctica al espacio digital, permitiendo que cada usuario construya un lugar de evocación personal mediante imágenes, objetos y relatos autobiográficos.

---

## Funcionalidades

- Construcción interactiva de una animita digital.
- Selección y manipulación libre de objetos.
- Incorporación de ofrendas al espacio de memoria.
- Escritura de una epicrisis o relato biográfico.
- Ambientación audiovisual mediante video y elementos en movimiento.

## Ejecución del proyecto

Para visualizar el proyecto localmente:

1. Descargar o clonar este repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar `index.html` utilizando Live Server.
